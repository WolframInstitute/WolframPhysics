# Wolfram Physics Project website sweep: functions, tools and vocabulary

Source swept: https://www.wolframphysics.org/ and the Wolfram Cloud objects it links to (the function guide pages, the hands-on notebook, the Registry of Notable Universe Models, the working-material archives), plus the project bulletins (bulletins.wolframphysics.org, read through the Wayback Machine because the host no longer resolves) and the two Gorard launch papers. Swept on 2026-09-16.

Conventions in the tables: Name is the exact symbol spelling. Source is WFR (Wolfram Function Repository), WL (built-in Wolfram Language symbol), the paclet name for paclet symbols, or Site for notebooks, pages and data resources. Description is quoted from the page where the function appears; where the site lists a function by name only, the description is the Function Repository description returned by the kernel lookup described under Method and is prefixed "WFR:". Status is "seen" when the function was seen in a fetched page or code file and (for WFR names) confirmed to resolve with ResourceObject; "unconfirmed" when it was only mentioned by name and could not be confirmed to exist.

## Method

Web fetches (curl from the sandbox unless stated; WebFetch is the Claude fetch tool):

1. https://www.wolframphysics.org/ (home; navigation links only, no functions). WebFetch.
2. https://www.wolframphysics.org/functions/ returned HTTP 404. https://www.wolframphysics.org/tools/functions/ also 404. The function catalog lives on the Wolfram Cloud guide page linked from /tools/.
3. https://www.wolframphysics.org/tools/ (Software Tools page). WebFetch and curl.
4. https://www.wolframcloud.com/obj/wolframphysics/Tools/guide-page (the "Wolfram Physics Project Functions" guide) and its six sub-guides: .../Tools/wolfram-models, .../Tools/multiway-systems, .../Tools/substitution-systems, .../Tools/additional-systems, .../Tools/combinators, .../Tools/utilities. Also https://www.wolframcloud.com/obj/e325c942-158e-485b-8cab-316c1c3cd866 (same guide page under its UUID). The HTML splits every character into its own span, so a small Python parser (parse_cloud.py) strips tags at block boundaries and collects the href targets; the small square marker before a name distinguishes WFR functions (linked to resources.wolframcloud.com/FunctionRepository/resources/Name) from built-ins (no marker).
5. https://www.wolframphysics.org/technical-introduction/ and all 120 section URLs from its sidebar (collected from the single-quoted sidebar hrefs of one section page). For each section the HTML was downloaded and every companion code text file referenced by data-c2c-file (the click-to-copy text behind each code image, e.g. img/appendix-implementation_io_18.en.txt) was downloaded: 1367 code files, 1.1 MB. The code corpus was grepped for ResourceFunction["..."] names, quoted property strings and called symbols; called symbols were checked with Names on the System context in the kernel. The prose was searched for links to reference.wolfram.com/language/ref/... to list the built-ins each section names.
6. https://www.wolframphysics.org/technical-introduction/additional-material/appendix-implementation/ , .../appendix-graph-types/ , .../tools-data-and-source-materials/ , .../notes-and-further-references/ , .../references/ (read in full). The Download Notebook links resolve to /technical-introduction/<section>.nb (nbUrl attribute) but were not downloaded because the .txt code files already contain every input.
7. https://www.wolframphysics.org/glossary/ (WebFetch, every term read).
8. https://www.wolframphysics.org/visual-summary/ , /visual-summary/dark/ , and the PDF /visual-summary/WolframPhysicsSummary.pdf (11.8 MB, converted with pdftotext).
9. https://www.wolframphysics.org/universes/ , /universes/2.html through /universes/5.html (pagination), and all 75 model pages /universes/wmNNNN/ (each about 550 KB; the code is inline text). The copy and download links (/universes/url/?u=wm1113&urlType=copy) redirect to a Wolfram Cloud sign-in and were not followed.
10. https://www.wolframphysics.org/bulletins/ redirects (301) to https://writings.stephenwolfram.com/category/physics/ , which was fetched (WebFetch) for the post list. bulletins.wolframphysics.org has no DNS record (verified with dig and with the kernel's Import); the bulletin index (/, /all-by-date) and the nine bulletins hosted natively on that host were read from https://web.archive.org/web/2024id_/https://bulletins.wolframphysics.org/... . Each bulletin's code lives in click-to-copy text files on content.wolfram.com (data-src attributes, e.g. https://content.wolfram.com/sites/32/2023/03/sw0520img9_copy.txt), which is live; all 934 code files were downloaded and grepped.
11. https://www.wolframphysics.org/technical-documents/ (full text and 193 links extracted), https://www.wolframcloud.com/obj/wolframphysics/Documents/some-relativistic-and-gravitational-properties-of-the-wolfram-model.pdf and .../some-quantum-mechanical-properties-of-the-wolfram-model.pdf (pdftotext, grepped for function names, SetReplace, Function Repository).
12. https://www.wolframphysics.org/archives/index/ and https://www.wolframphysics.org/archives/index?i=YEAR for every year listed (1994 to 2004, 2015, 2019 to 2026); notebook links are https://www.wolframcloud.com/obj/wolframphysics/WorkingMaterial/YEAR/Name.nb (1649 notebooks in 2015 to 2026; the 1994 to 2004 years are sub-folders such as 1997/Universe and were not expanded). Twelve notebooks were downloaded through the raw endpoint https://www.wolframcloud.com/download/wolframphysics/WorkingMaterial/... and grepped: 2020/WFRDemo-01, 2020/CausalGraphs-01, 2020/Physics-01, 2020/GenerationalMultiway-01, 2020/BranchialWM-01, 2020/LocalMultiwaySystems-01, 2020/WMCausalInvariance-01, 2020/Foliations-01, 2021/RulialSpace-01, 2021/Foliations-01-maxp, 2026/HypergraphRewriting-01, 2026/EntropyOfSpace-01.
13. https://www.wolframcloud.com/obj/wolframphysics/Tools/hands-on-introduction-to-the-wolfram-physics-project.nb (the cloud HTML view has collapsed sections). The raw notebook (24.9 MB) was obtained from https://www.wolframcloud.com/download/wolframphysics/Tools/hands-on-introduction-to-the-wolfram-physics-project.nb with the kernel's URLDownload after curl was cut off twice (HTTP/2 stream errors, no range support). The notebook was read with Get and every Input, Text and Section cell converted to InputForm text (nbtext.wls).
14. https://www.wolframphysics.org/questions/ and its six category pages (general, scientific-general-interest, relations-to-other-approaches, spacetime-relativity, quantum-mechanics, computation-theory): no function names.
15. https://www.wolframphysics.org/visual-gallery/ (empty without JavaScript), /education-collaboration/ , /help/ , /peer-review/ , /pages/technical-introduction/references/external/ : no function names beyond a mention of "our core simulation code repo or function repository" on /help/.
16. https://www.wolframphysics.org/wolfram-physics-project-summer-school/ returned 404. WebSearch "site:wolframphysics.org summer school" found only /education-collaboration/ and /technical-documents/ (which carries the student project list as Wolfram Community links).
17. https://resources.wolframcloud.com/FunctionRepository/resources/InteractiveListSelector (WebFetch, to get the description of a resource the kernel could not resolve because of a stale local copy).

Kernel evaluations (WL 15.0, wolframscript -file, cloud connected):

- wfr-lookup.wls: ResourceObject[name] for the 127 candidate names collected from all pages, printing ResourceType, Description, ContributorInformation and Keywords, each wrapped in TimeConstrained[..., 90]. 124 resolved; InteractiveListSelector, BranchialGraph and CanonicalizeSymbols did not.
- wfr-check2.wls: repeated lookups for the eight doubtful names and URLRead[url, "StatusCode"] on their repository pages: InteractiveListSelector 200, WolframModelRuleProduct 200, HyperbolicTilingGraph 200, FindCanonicalHypergraph 200, BranchialGraph 401, CanonicalizeSymbols 401.
- syscheck.wls: Names of the System context symbol (`` Names["System`" <> name] ``) for the 269 symbols called at least twice in the technical-introduction code, to separate built-ins from private helper definitions.
- fetch_bulletins.wls: Import[url, "Text"] on bulletins.wolframphysics.org (failed; confirms the host is gone).
- dl-handson.wls and nbtext.wls: URLDownload of the hands-on notebook and conversion of its cells to text.

Scripts and downloaded material are under the session scratchpad (ti/, bulletins/, universes/, archives/, techdocs/).

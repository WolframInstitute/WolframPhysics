# Paclet Repository and published paclets relevant to the Wolfram Physics Project

Survey of the Wolfram Language Paclet Repository (all 260 listed paclets), the Wolfram paclet server (SetReplace), the WolframInstitute GitHub organization (35 repositories) and a few individual GitHub paclets, for everything usable in Wolfram Physics Project work: hypergraph rewriting, Wolfram models, multiway systems, causal and branchial graphs, token-event graphs, rulial and metamathematical rewriting, Turing machines, cellular automata, network systems, lambda calculus, combinators, tag systems, quantum framework objects, discrete geometry and causal-structure tools. Every symbol row was seen either on a repository guide or reference page, in a reference notebook shipped inside the installed paclet, in a kernel evaluation (Names, usage messages, PacletObject), or in a GitHub source file; the Source and URL columns say which. Symbols known only by name are marked unconfirmed. Property strings (WolframModel properties, HGEvolve properties, Multi properties) are listed in their own tables with the name in quotes because they are strings, not symbols.

## Summary of what exists

- The Paclet Repository has 260 paclets (all-data.json, September 2026). Five are published by WolframInstitute: Hypergraph 1.2.3, NetworkSystem 1.1.5, PiMachine 1.0.3, TuringMachine 1.2.0, Z3Link 1.0.2. Wolfram-published paclets relevant here: Multicomputation 0.1.8, QuantumFramework 2.1.1, Lambda 1.2.4, DiagrammaticComputation 1.0.8, TensorNetworks 1.0.11, GeometricAlgebra 1.4. Community cellular automaton paclets: KlausSutner/Automata 1.0.2, Obando/CAGenetics 1.0.2, DanielS/Wireworld 1.0.8, DenizYoldas/QuantumBlockCellularAutomata 1.0.0.
- SetReplace 0.3.196 (the official Physics Project paclet) is on the Wolfram paclet server, not the Paclet Repository.
- WolframInstitute/HypergraphRewriteEngine (HGEvolve, HGSession*), WolframInstitute/CellularAutomaton, WolframInstitute/Infrageometry, SyntheticInfrageometry, InfraCausality, InfraGaugeTheory, InfraAnalysis, InfraUniverseRegistry, Gravitas and Wolfram/Metamathematics exist as GitHub or wolframcloud .paclet installs only; ResourceObject on each name failed.
- No paclet named WolframPhysicsProjectStyles, Wolfram/Combinators, WolframInstitute/Combinators, or containing Multiway, Rulial, CausalSet, TokenEvent or Ruliology exists on the Paclet Repository (searched the full name list and ResourceObject). Combinator evolution exists as the GitHub paclet maxitg/CombinatorEvolve and as Function Repository functions (other finders). Styles live in SetReplace (SetReplaceStyleData; WolframPhysicsProjectStyleData is deprecated there) and in the Function Repository function WolframPhysicsProjectStyleData.

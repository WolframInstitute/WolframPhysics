# Unlisted functions audit

Summary: every inventory row with status seen and a source in the Function Repository, the built-in language, a paclet, the nikm cloud or GitHub was checked against the 35 guide pages; the Function Repository was then swept directly through its search API for the twenty-seven terms of the task and 107 further terms, the Wolfram Physics Project category listing was compared with the pages, and every writings-defined function listed on a page was searched for a published twin. Of the 1666 in-scope rows on no page (1467 of them already marked not for the guide), 1631 stay off the pages for the reasons tabled in section E and 35 become entries; with 96 symbols the inventory carried only inside group rows, 5 rows it left unconfirmed and 44 symbols it did not carry at all (the experimental QuantumFramework exports, the Wolfram/TensorNetworks and Wolfram/LeanLink paclets, two Function Repository functions and three nikm data resources), they make the 180 new entries of section A. Section B adds 41 cross-listings, the largest being the quantum circuit multiway, causal and token-event graphs of Wolfram/QuantumFramework onto Multiway Systems and Causal Graphs. Section C records the two published twins of writings functions the sweep found (PosetToTableau and TableauToPoset); FindBooleanAlternative, the twin the task named, was already on Axiom Systems and Entailment. The direct sweep found four Function Repository functions absent from both the inventory and the pages that belong on a page (SimplicialHomologyGroup, GraphRandomWalk and the two tableau twins) and confirmed that the Wolfram Physics Project category is fully listed but for three functions judged irrelevant. Every URL in section A to C was fetched on 2026-09-21 and every Function Repository name was confirmed with ResourceObject in the WL 15.0 kernel. Nothing was deployed or committed; no guide page was edited.

## Method

Every step ran on 2026-09-21 from the repository root or the session scratchpad (scratchpad/audit). The kernel is wolframscript 15.0, run with -file on scratch .wls scripts.

1. Pages: audit/extract_listed.py read the 35 files under docs/en/Guides, dropped the frontmatter and collected every code span and every link text (2642 distinct names with the pages they sit on, audit/listed.json). A name counts as listed when it appears as a chip or as the code span of a link anywhere on a page, headline or tail.
2. Inventory pass: audit/compare.py took every row of scratchpad/inventory/merged.json (6289 rows) with status seen and source WFR, WL, SetReplace, a Publisher/Paclet paclet, Cloud:nikm or GitHub:owner/repo (4177 rows) and checked the name against the pages: 1666 rows are on no page, 199 of them in a guide section and 1467 marked Not for the guide. Group rows (names ending in symbols, options, properties and the like) were expanded into their member symbols and each member checked separately (87 group rows, 1063 members, 236 unlisted members).
3. Source re-reads for the unlisted members and the paclets with unlisted rows: raw GitHub files were fetched and their PackageExport lines and usage messages parsed (WolframResearch/QuantumFramework Kernel/Experimental.m, Multiway.m, Usage.m, QuantumCircuitOperator/Properties.m and TensorNetwork.m; WolframInstitute/Multicomputation Kernel/LinkedHypergraph.m and Graph.m; WolframInstitute/SyntheticInfrageometry Kernel/Usage.wl; WolframInstitute/Infrageometry Kernel/Usage.wl; WolframInstitute/InfraAnalysis Kernel/Usage.wl; every Kernel file of InfraGaugeTheory and InfraCausality; maxitg/OrientedGraph OrientedGraph.wl and README; maxitg/SetReplace README and Documentation/Generators; WolframInstitute/WolframLambda Kernel/Lambda.wl and PacletInfo; the Kernel trees of HypergraphRewritingEngine, CellularAutomaton, IteratedFiniteAutomaton, PiMachine, DiagrammaticComputation, sw1sh/WolframMetamathematics, PostTagSystem, CombinatorEvolve, asheux/NetworkSystem, TuringMachine, Hypergraph, WolframInstitute/Gravitas, ProgramGames and InfraUniverseRegistry through the GitHub trees API with gh). The Paclet Repository pages of WolframInstitute/Hypergraph, Wolfram/Lambda, Wolfram/QuantumFramework, Wolfram/Multicomputation, WolframInstitute/TuringMachine, WolframInstitute/NetworkSystem, Wolfram/LeanLink, Wolfram/TensorNetworks, Wolfram/DiagrammaticComputation and WolframInstitute/PiMachine were fetched and their ref links compared with the pages and the inventory; the guide pages of LeanLink and TensorNetworks were read for the one-line descriptions. Fourteen other paclet addresses on the Paclet Repository redirect to the account sign-in page (CellularAutomaton, IteratedFiniteAutomaton, Infrageometry, InfraCausality, SyntheticInfrageometry, InfraGaugeTheory, InfraAnalysis, HypergraphRewriteEngine, Metamathematics, Ruliobiology, ProgramGames, Gravitas) and are linked through GitHub or the nikm cloud as the pages already do.
4. Repository visibility: curl of the GitHub repository page of every paclet the pages link. WolframInstitute/PersistenceRewriting, WolframInstitute/Ruliobiology and WolframInstitute/PureMath return 404 anonymously (gh api confirms PersistenceRewriting is private); PureMath is linked through its wolframinstitute cloud deployment, the other two have no anonymous home (section F).
5. Direct Function Repository sweep: the search page https://resources.wolframcloud.com/FunctionRepository/search?i=TERM loads its results from https://www.wolframcloud.com/obj/resourcesystem/api/1.0/SearchResources?ResourceTypes=Function&Format=json&Count=1000&WebFiltering=True&Query=TERM (read from results-controller.js), so audit/wfr_search.py queried that endpoint for the twenty-seven terms of the task and 107 further terms (rewriting, multicomputation, ruliad, observer, foliation, light cone, Lorentz, relativity, quantum, entanglement, category, functor, string diagram, monoidal, isomorphism, canonical, graph automorphism, Ricci, Ollivier, Forman, simplicial, Betti, homology, persistent, dimension, graph distance, ball, cyclic tag, sequential substitution, mobile automaton, network system, NKS, rule space, rule enumeration, busy beaver, halting, SK, S combinator, lambda calculus, beta reduction, equational, theorem, entailment, metamathematics, logic, Boolean, sequent, natural deduction, automaton, finite automaton, regular language, state machine, counter machine, L-system, Lindenmayer, graph rewriting, double pushout, confluence, critical pair, normal form, term rewriting, string substitution, nest graph, states graph, evolution graph, transitive reduction, partial order, poset, DAG, Hasse, hyperbolic, Cayley graph, group, monoid, semigroup, Weyl, Dynkin, layered graph, graph layout, particle, black hole, gravity, Einstein, metric, manifold, discrete, mesh, lattice, tiling, physics, expression rewriting, pattern, replace, position, subexpression, tree graph, expression tree, Wolfram Physics, Gorard, generational, glocal, multihistory, event, history, time), 2725 distinct resources in all (audit/wfr_search_results.json). The category listing https://www.wolframcloud.com/obj/resourcesystem/published/FunctionRepository/category/wolfram-physics-project-data.json (221 resources) was compared with the pages and the inventory. Each result not on any page and not in merged.json was read by description and, when a page could use it, confirmed with ResourceObject in the kernel (audit/confirm_wfr.wls, kernel 15.0) and its page fetched by name.
6. Twins: audit/twin_search.py queried the same endpoint with the split words of each of the 1063 function-like names sourced to the writings, wolframphysics.org, the archives, the Institute or Community, and compared the labels returned with the name (exact, singular or plural, and prefix-stripped forms) and their descriptions with the name's words; the inventory notes were also grepped for recorded twin relations.
7. Every URL of sections A to C (93 distinct) was fetched with curl following redirects and its final address and title recorded (audit/url_check.json): all return 200 and none lands on a sign-in page. Every Function Repository name in those sections resolved with ResourceObject in the kernel (audit/confirm_wfr.log).
8. wolframscript -file scripts/lint_docs.wls from the repository root, clean over the whole tree with this file in place.

The pages were not edited: this is a finder report. The page names below are the guide Names (Area/Leaf, or the top-level leaf name), and the tag column is the provenance tag the entry takes in a thematic subsection (dropped under a per-source heading).

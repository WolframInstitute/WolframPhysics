# Wolfram Institute sweep: existing Wolfram Language functions for the Wolfram Physics Project

Research report for the WolframInstitute/WolframPhysics guide page. Source swept: the Wolfram Institute (website, GitHub organization, Paclet Repository publisher, nikm cloud deployed resources, Function Repository contributions by fellows, arXiv papers by fellows). Date of sweep: 16 September 2026. Kernel: WL 15.0 via wolframscript, cloud-connected as nikm.

## Verification

Independent check of every row of the 16 findings tables by a second agent on 2026-09-16 (WL 15.0 via wolframscript, cloud-connected as nikm; GitHub via git and gh; web pages via WebFetch). Result: 726 rows checked, 723 confirmed as seen, 3 left unconfirmed, 0 removed.

### Method

- WFR rows (141 rows, 129 distinct names, tables 9 and 16): one scratch script evaluated Quiet@ResourceObject[name] with the properties ResourceType, Description and ContributorInformation for every name, each wrapped in TimeConstrained of 60 seconds. All 129 names resolved with ResourceType "Function" (contributors seen: Jonathan Gorard, Nikolay Murzin, Wolfram Research, Stephen Wolfram with Jonathan Gorard and Max Piskunov, and others). Five randomly chosen rows (SolveVacuumEinsteinEquations, MultiwaySemigroup, DiscreteHypersurfaceDecomposition, CPDecomposition, MultiwayMonoid) were also fetched at their URLs and each page documents the named function.
- Paclet rows published on the Paclet Repository or the paclet server (tables 1, 2, 4, 10, 11, 12 NetworkSystem, 13 PiMachine): PacletInstall in a scratch kernel of WolframInstitute/Hypergraph 1.2.3, WolframInstitute/TuringMachine 1.2.0, WolframInstitute/PiMachine 1.0.3, WolframInstitute/NetworkSystem 1.1.5, WolframInstitute/Z3Link 1.0.2, Wolfram/Multicomputation 0.1.9, Wolfram/Lambda 1.2.4 and WolframInstitute/HypergraphRewriteEngine 0.0.1, then Needs of the primary context and Names of every context the paclet declares. Every Hypergraph, Multicomputation, Lambda, NetworkSystem and PiMachine row is in Names. The 22 TuringMachine rows of the InductiveProofs group are in the `` WolframInstitute`TuringMachine`InductiveProofs` `` context of the installed 1.2.0 paclet with usage messages. Three Paclet Repository reference pages (OneSidedTuringMachineFind, HypergraphInsertionBracket, PiEvalTrace) were fetched as URL spot checks and each documents the named symbol.
- Cloud-deployed paclet rows (tables 14 and 15, nikm DeployedResources pages): ResourceObject of the cloud object followed by PacletInstall of the resource for THVMLink (0.1.0), PureMath (0.0.2), Gym (0.0.1), PrimeIntellect (1.0.0) and MarkdownToNotebook. All 13 THVMLink function rows are in Names of the THVMLink contexts; 42 of the 48 PureMath rows are in Names of the cloud 0.0.2 paclet and the other 6 (FriedmannEquations, KomarMass, HawkingTemperature, BekensteinHawkingEntropy, PetrovType, CongruenceExpansion) have usage messages in the GitHub 0.5.0 source their URL points to. The Gym page was also fetched and lists the symbols the row names.
- GitHub-sourced rows (tables 3, 5, 6, 7, 8, 9, 12, 13, 14, 15): shallow clones of all 29 WolframInstitute repositories named in the tables (including SetReplace, Gravitas, PureMath and Infrageometry, which the original sweep could not clone), then a grep of every row name for a PacletInfo.wl Symbols entry, a PackageExport call, a usage message or a definition. Evidence per table: HypergraphRewriteEngine 7 PackageExport in paclet/Kernel/HypergraphRewriting.wl; SetReplace 42 PackageExport in Kernel/*.m; PersistenceRewriting 17 PackageExport; Infrageometry 62 PackageExport; InfraCausality 68 PackageExport; Gravitas 11 definitions, one per Kernel file, each file listed in the loader Gravitas.wl; CellularAutomaton, Ruliobiology, ProgramGames, IteratedFiniteAutomaton, DiagrammaticComputation and PiMachine rows in PacletInfo Symbols lists or usage messages; PureMath 48 usage messages in Kernel/MathematicalPhysics, Kernel/Geometry and Kernel/Topology; SyntheticInfrageometry, InfraGaugeTheory and InfraAnalysis rows PackageExport. Every GitHub file path used as a row URL exists in the clone on the branch the URL names, except the two Multicomputation URLs corrected below. Paclet-level rows were checked against the repository PacletInfo.wl Name and Version.
- No WL built-in rows are present in the tables, so no `` Names["System`*"] `` check was needed.

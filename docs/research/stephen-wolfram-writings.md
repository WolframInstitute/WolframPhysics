# Stephen Wolfram Writings sweep: Wolfram Language functions used by the Wolfram Physics Project

Research report for the WolframInstitute/WolframPhysics paclet guide page. Source swept: writings.stephenwolfram.com (2020 to 2026), the four Wolfram Physics bulletins that the writings site redirects to, and the online technical introduction "A Class of Models with the Potential to Represent Fundamental Physics". Sweep date: 2026-09-16. Kernel: WL 15.0 via wolframscript.

Status column: "seen" means the function was seen in evaluated input on a fetched page and its existence was confirmed on its own public page (Function Repository page, Paclet Repository page or installed paclet, or the System context of WL 15); "unconfirmed" means the name was seen in the post code but no public page or installed definition could be confirmed. Names that begin with a dollar sign are written in code spans.

## Method

Every step below was actually run; the scratch files live under the session scratchpad directory (sw/).

1. Enumerated posts. Downloaded with curl the category pages physics (5 pages), ruliology (4), multicomputation (2), new-kind-of-science (6), mathematics (4), computational-science (4) and the year archives 2020 to 2026 of https://writings.stephenwolfram.com/ and collected every 2020 to 2026 post URL (92 posts, listed in the legend below).
2. Downloaded all 92 posts with curl. Code inputs are embedded in three ways depending on the year: `<pre class="text">` blocks (2020 to early 2021), `<div class="IFL" data-src="..._copy.txt">` lazy-loaded box expressions (2021 to 2022) and `data-c2c-file="..._copy.txt"` click-to-copy box expressions (2023 to 2026). All 5996 referenced .txt files on content.wolfram.com were downloaded in parallel (script fetch.py, dl.sh).
3. Extracted names with Python regexes (analyze2.py, meta.py): ResourceFunction["Name"] in plain text; in box form the token sequences "ResourceFunction", "[", "\"\<Name\>\"" and "\"Name\""; the icon form StyleBox["\<\"Name\"\>", "ResourceFunctionLabel"]; the embedded ResourceObject metadata ("Name", "UUID", "ResourceType" -> "Function", "DocumentationLink", "ResourceLocations"); PacletSymbol["Publisher/Name", "Symbol"]; Needs, Get and PacletInstall arguments; context-qualified names; and every capitalized symbol head followed by "[" (for built-ins).
4. Classified every ResourceFunction name by an HTTP request to https://resources.wolframcloud.com/FunctionRepository/resources/NAME/ (200 = public Function Repository page, 302 = not in the repository; wfrcheck.sh). For the non-repository names, the DocumentationLink recorded in the post metadata (cloud objects under wolframphysics, sw-writings, sw-writings0, richardassar, nikm) was fetched and checked for a "Function Resource" page (docchk.sh).
5. Kernel evaluations (wolframscript -file): ResourceObject[name]["Description"], ["Keywords"], ["ContributorInformation"], ["Usage"] for every public repository name (kernel1.wls, kernel5.wls); `` Names["System`*"] `` membership and ::usage for every symbol head (kernel1.wls); PacletFind and PacletFindRemote for Wolfram/Multicomputation, WolframInstitute/Hypergraph, WolframInstitute/TuringMachine, Wolfram/Lambda, Wolfram/LeanLink, SetReplace (kernel2.wls; PacletFindRemote returned empty lists in this session, all six paclets were already installed locally: versions 0.1.9, 1.2.3, 1.2.0, 1.2.4, 1.0.7, 0.3.196); `` Names["Context`*"] `` for each paclet context and intersection with the symbols used in each post (kernel3.wls); ResourceObject[CloudObject[url]] on private resources (kernel4.wls; they carry no Description property); usage text extracted from the paclets' Documentation/English/ReferencePages/Symbols/*.nb (kernel7.wls) and from SetUsage strings in the SetReplace Kernel sources.
6. Verified Paclet Repository reference pages https://resources.wolframcloud.com/PacletRepository/resources/PUBLISHER/NAME/ref/SYMBOL.html for every paclet symbol used (refchk.sh; a missing page redirects to a sign-in page).
7. Bulletins. Four posts listed on the writings site redirect to bulletins.wolframphysics.org, which did not resolve from this machine (DNS failure with curl and WebFetch). They were fetched from the Wayback Machine (https://web.archive.org/web/2024id_/URL, with the compressed option of curl) and their code files (content.wolfram.com/sites/32/...) downloaded directly (analyze_bull.py). The arXiv PDFs 2103.04961 and 2101.10907 were also downloaded; their code is images only, so they were not used.
8. Technical introduction. Crawled https://www.wolframphysics.org/technical-introduction/ by following the next-page links from the Introduction (ti_crawl.py) and downloaded every data-c2c-file code file (plain text).
9. Web searches run: "Multiway Turing Machines" Stephen Wolfram 2021 bulletin (WebSearch, to locate the bulletin and its arXiv copy).
